# Security Policy

PDF Shuffle processes all files locally in the browser; nothing is uploaded.
Still, if you discover a vulnerability (for example in the way PDFs are parsed,
the Content Security Policy, or the build/deploy pipeline), please report it
privately.

- Email: info@9xb.de
- Please include steps to reproduce and, if possible, a sample file.

You will receive a response within 7 days. Please do not open a public issue
for security reports until a fix has been released.

Dependencies are monitored with Dependabot and `npm audit` runs in CI.
